Como usar: clique dentro do tablet para navegar (capa → carta → categoria → detalhe → Sofia) ou use os botões acima. Medidas liga os contornos com as dimensões da spec. O layout responde pela largura do próprio tablet (container query): ≥ 1024px = barra lateral + painel; < 1024px = faixa de chips + lista de 1 coluna. Dados e fotos são fictícios (protótipo). Tokens: valores do protótipo v2 com --faint em 0,50 (spec 6.2). Fonte: vinia-docs/docs/front-end-spec.md.
