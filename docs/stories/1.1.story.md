## Story

Como **developer**, quero ter o projeto Laravel 11 configurado com PostgreSQL, autenticação Sanctum e o layout do backoffice pronto, para que todas as features subsequentes possam ser desenvolvidas sobre uma base sólida.

### Configuração R2 (em `config/filesystems.php`)
```php
'r2' => [
    'driver'                  => 's3',
    'key'                     => env('CLOUDFLARE_R2_ACCESS_KEY'),
    'secret'                  => env('CLOUDFLARE_R2_SECRET_KEY'),
    'region'                  => 'auto',
    'bucket'                  => env('CLOUDFLARE_R2_BUCKET'),
    'url'                     => env('CLOUDFLARE_R2_PUBLIC_URL'),
    'endpoint'                => env('CLOUDFLARE_R2_ENDPOINT'),
    'use_path_style_endpoint' => true,
    'visibility'              => 'public',
],
```

### Rotas do backoffice
```php
// routes/web.php
Route::prefix('backoffice')->name('backoffice.')->group(function () {
    Route::middleware('guest')->group(function () {
        Route::get('/login', [AuthController::class, 'showLogin'])->name('login');
        Route::post('/login', [AuthController::class, 'login'])->name('login.post');
    });
    Route::middleware('auth')->group(function () {
        Route::get('/dashboard', DashboardController::class)->name('dashboard');
        Route::post('/logout', [AuthController::class, 'logout'])->name('logout');
    });
});
```

### AdminSeeder
```php
User::create([
    'name'              => 'Admin Vinia',
    'email'             => 'admin@vinia.app',
    'password'          => Hash::make('password'),
    'role'              => 'admin',
    'restaurant_id'     => null,  // admin não pertence a restaurante
    'email_verified_at' => now(),
]);
```
> Nota: `restaurant_id` precisa ser nullable na migration de users.
