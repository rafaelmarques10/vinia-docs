## Story

Como **tablet autenticado**, quero criar e gerenciar sessões anônimas dos comensais, para que cada visita seja rastreada com UUID único e o perfil de paladar coletado possa ser usado nas recomendações de IA.

---

## Contexto

A sessão é criada automaticamente quando o comensal toca "Ver Carta" no React. Identificada por UUID (não BIGINT) para dificultar enumeração. O `palate_profile` (JSONB) armazena as respostas do fluxo de 4 perguntas e é injetado nas chamadas de IA subsequentes. Sessão encerrada pelo timeout de inatividade do React.

## Dev Notes

### Controller
```php
// app/Http/Controllers/Api/ComensalSessionController.php

public function store(Request $request): JsonResponse
{
    $tablet = $request->tablet;
    $session = ComensalSession::create([
        'id'            => Str::uuid(),
        'tablet_id'     => $tablet->id,
        'restaurant_id' => $tablet->restaurant_id,
        'started_at'    => now(),
    ]);
    return response()->json(['data' => ['session_id' => $session->id]], 201);
}

public function update(Request $request, ComensalSession $session): JsonResponse
{
    // Verificar ownership: session.tablet_id === request.tablet.id
    abort_if($session->tablet_id !== $request->tablet->id, 403);

    $session->update($request->only(['palate_profile', 'ended_at']));
    return response()->json(['data' => ['session_id' => $session->id]]);
}
```

### Estrutura do palate_profile (JSONB)
```json
{
  "color_preference": "tinto",
  "body_preference": "encorpado",
  "taste_preference": "seco",
  "price_range": "200-500",
  "collected_at": "2026-06-18T20:30:00Z"
}
```

### Validação do PATCH
```php
$validated = $request->validate([
    'palate_profile'              => 'nullable|array',
    'palate_profile.color_preference' => 'nullable|in:tinto,branco,rosé,espumante,surpresa',
    'palate_profile.body_preference'  => 'nullable|in:leve,medio,encorpado',
    'palate_profile.taste_preference' => 'nullable|in:seco,frutado,doce',
    'palate_profile.price_range'      => 'nullable|string',
    'ended_at'                    => 'nullable|date',
]);
```
