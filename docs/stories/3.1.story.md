## Story

Como **gerente autenticado**, quero cadastrar e gerenciar os tablets que exibem a carta digital, com controle por token único por dispositivo, para que apenas dispositivos autorizados acessem a carta do meu restaurante.

---

## Contexto

Cada tablet é um dispositivo físico autenticado por um token de 64 chars. O gerente cadastra, vê o status online/offline e pode revogar ou regenerar tokens. O número máximo de tablets ativos é limitado pelo plano do restaurante. O middleware `TabletAuthentication` é o componente central — todas as rotas da API do tablet passam por ele.

**IN:**
- `TabletService` com `create()`, `regenerateToken()`, `revoke()`, `canAddTablet()`
- Middleware `TabletAuthentication` para rotas `/api/v1/`
- Livewire `TabletList` com polling de status (30s) e modais de token/QR
- Limite de tablets por plano (starter:1, standard:3, premium:6)
- `last_seen_at` atualizado em cada request autenticado da API

**OUT:**
- QR code real (pode ser exibido o token como texto no MVP, QR code como melhoria)
- Tablets adicionais com custo extra (só exibir mensagem informativa)
- App nativo — o tablet usa browser

### Middleware TabletAuthentication
```php
// app/Http/Middleware/TabletAuthentication.php

public function handle(Request $request, Closure $next): Response
{
    $token = $request->bearerToken();
    $tablet = Tablet::where('token', $token)->where('active', true)->first();

    if (!$tablet) {
        return response()->json(['error' => ['code' => 'UNAUTHORIZED', ...]], 401);
    }

    $tablet->update(['last_seen_at' => now()]);
    $request->merge(['tablet' => $tablet, 'restaurant' => $tablet->restaurant]);

    return $next($request);
}
```

### Registro do middleware
```php
// bootstrap/app.php (Laravel 11)
```
