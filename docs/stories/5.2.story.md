## Story

Como **comensal**, quero navegar pela carta de vinhos com filtros intuitivos e ver o detalhe completo de cada rótulo no tablet, para explorar o acervo e encontrar o vinho ideal para minha refeição.

---

## Contexto

A tela de entrada exibe logo do restaurante e botão "Ver Carta". Ao tocar, cria sessão e exibe a listagem. A listagem tem filtros (tipo, país, uva, preço) e polling de 60s que atualiza disponibilidade sem recarregar a página. O detalhe exibe ficha técnica completa com botão para a Sofia. Timeout de inatividade (3min) retorna à entrada.

### useWines — React Query com polling e filtros

```typescript
// src/hooks/useWines.ts
export function useWines(filters: WineFilters = {}) {
  return useQuery({
    queryKey: ['wines', filters],
    queryFn: () => api.getWines(filters),
    staleTime: 60_000,
    refetchInterval: 60_000,
  });
}

// WineFilters type:
interface WineFilters {
  type?: string;
  country?: string;
  grape?: string;
  min_price?: number;
  max_price?: number;
}
```

### useSession — criação e encerramento
```typescript
// src/hooks/useSession.ts
export function useSession() {
  const [sessionId, setSessionId] = useState<string | null>(null);

  const startSession = async () => {
    const { session_id } = await api.createSession();
    setSessionId(session_id);
    return session_id;
  };

  const endSession = async () => {
    if (!sessionId) return;
    await api.updateSession(sessionId, { ended_at: new Date().toISOString() });
    setSessionId(null);
  };

  return { sessionId, startSession, endSession };
}
```
