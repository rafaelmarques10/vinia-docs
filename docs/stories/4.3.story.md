# Story 4.3: F007 — IA Comparativo entre Rótulos

**Status:** Done
**Epic:** 4 — Sofia IA — Recomendações
**Sprint:** 3 (Semana 7)
**Story Points:** 5
**Spec:** `vinia-specs/features/F007-ai-compare-F008-session.md`

---

## Story

Como **comensal**, quero comparar dois rótulos da carta via Sofia, recebendo uma análise comparativa em linguagem elegante que me ajude a decidir qual vinho escolher, sem que a IA declare um "vencedor".

---

## Contexto

O comensal seleciona 2 rótulos na carta React e solicita o comparativo. Sofia recebe as fichas técnicas completas de ambos e gera análise cobrindo estilo, perfil aromático, harmonizações e perfil de comensal ideal — sempre em português, sem declarar vencedor. O comparativo conta como 1 interação no rate limit da sessão (compartilhado com F006).

**Referências de spec:**
- `vinia-specs/features/F007-ai-compare-F008-session.md`
- `vinia-specs/ai/PROMPTS.md` — prompt de comparativo

---

## Critérios de Aceite

- [x] **CA01**: `type=compare` com 2 wine_ids válidos retorna análise cobrindo estilo, perfil aromático, harmonizações e perfil de comensal ideal
- [x] **CA02**: Análise não declara vencedor — conclui com pergunta que ajuda o comensal a decidir
- [x] **CA03**: Rótulo desativado entre carregamento e solicitação → 422 "Um dos rótulos selecionados não está mais disponível"
- [x] **CA04**: Comparativo conta no rate limit da sessão (compartilhado com recommend_*)
- [x] **CA05**: Ambos os rótulos devem pertencer ao restaurante da sessão (não pode comparar de restaurantes diferentes)
- [x] **CA06**: `buildComparePrompt(Wine $wineA, Wine $wineB)` injeta fichas técnicas completas de ambos

## Dev Notes

### Prompt — Comparativo (de PROMPTS.md)
```
Tipo: compare

User prompt:
O comensal quer comparar dois vinhos da nossa carta:

Vinho A: {wine_a_name} ({wine_a_vintage})
{wine_a_details}

Vinho B: {wine_b_name} ({wine_b_vintage})
{wine_b_details}

Faça uma análise comparativa elegante entre os dois, abordando:
1. Estilo e corpo — como diferem na estrutura
2. Perfil aromático e de sabor — o que cada um oferece ao paladar
3. Harmonização — com quais pratos cada um brilha mais
4. Para qual perfil de comensal cada um é mais indicado

Importante: não declare um "vencedor". Ajude o comensal a escolher com base no seu gosto
e no que vai pedir. Finalize com uma pergunta que ajude o comensal a decidir.
```
