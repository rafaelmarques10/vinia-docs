## Story

Como **comensal**, quero conversar com a Sofia no tablet para receber recomendações de vinho por prato, por perfil de paladar ou um comparativo entre dois rótulos, com a resposta exibida de forma elegante como se Sofia estivesse digitando.

---

## Contexto

A `AssistantPage` é a tela mais complexa do React — integra os 3 fluxos de IA via polling, apresenta 4 perguntas guiadas para o perfil de paladar, permite selecionar 2 rótulos para comparar, e exibe a resposta da Sofia com animação de digitação. O `session_id` (criado na Story 5.2) é enviado em todas as chamadas de IA.

## Dev Notes

### useAiInteraction — polling
```typescript
// src/hooks/useAiInteraction.ts
export function useAiInteraction(interactionId: string | null) {
  return useQuery({
    queryKey: ['ai-interaction', interactionId],
    queryFn: () => api.getInteraction(interactionId!),
    enabled: !!interactionId,
    refetchInterval: (data) => {
      if (data?.status === 'done' || data?.status === 'failed') return false;
      return 1500; // polling a cada 1,5s
    },
  });
}
```
