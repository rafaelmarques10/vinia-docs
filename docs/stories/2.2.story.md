# Story 2.2: F002 — Catálogo de Vinhos (CRUD + Fotos)

**Status:** Done
**Epic:** 2 — Backoffice — Restaurante & Vinhos
**Sprint:** 1–2 (Semanas 2–3)
**Story Points:** 8
**Spec:** `vinia-specs/features/F002-wine-catalog.md`

---

## Story

Como **gerente autenticado**, quero cadastrar, editar, ativar/desativar e excluir os rótulos da carta de vinhos do meu restaurante, incluindo upload de foto e associação de uvas, para que a carta digital reflita sempre o acervo real disponível.

---

## Contexto

O catálogo é o coração do backoffice — todos os rótulos que o comensal verá no tablet são gerenciados aqui. A disponibilidade (`available`) é o toggle mais importante: quando false, o rótulo some da carta imediatamente. Multi-tenancy estrito: o gerente só acessa seus próprios rótulos.

**Referências de spec:**
- `vinia-specs/features/F002-wine-catalog.md`
- `vinia-specs/database/schema.md` — tabelas `wines`, `grapes`, `grape_wine`

**IN:**

- `WinePolicy` — gerente só acessa rótulos do próprio restaurante

- Livewire `WineList` — listagem paginada com filtros, busca e toggle rápido
- Campo de uvas com autocomplete (busca em uvas já cadastradas)

**OUT:**
- Importação via planilha (Story 2.3)
- Ordenação na carta digital (feita na API — Story 3.2)
- Foto deletada do R2 ao excluir (obrigatório — incluído no delete)

### WinePolicy
```php
// app/Policies/WinePolicy.php
public function viewAny(User $user): bool
    → true (qualquer autenticado pode listar — filtrado por restaurant_id)
public function view/update/delete(User $user, Wine $wine): bool
    → $user->restaurant_id === $wine->restaurant_id || $user->role === 'admin'
```

### Campos e validação (de F002 spec)
```
name: required|string|min:2|max:255
producer: required|string|min:2|max:255
vintage: nullable|integer|min:1900|max:year()
country: required|string|min:2|max:100
region: nullable|string|max:255
type: required|in:tinto,branco,rosé,espumante,sobremesa,fortificado
alcohol: nullable|decimal:1|min:0.1|max:99.9
price: required|decimal:2|min:0.01|max:99999.99
description: nullable|string|max:2000
tasting_notes: nullable|string|max:2000
pairings: nullable|string|max:1000
photo: nullable|image|mimes:png,jpg,jpeg|max:5120
available: boolean (default: true)
grapes: nullable|array (nomes das uvas)
```

### Livewire WineList — listagem
- Paginação: 20 por página (`Wine::paginate(20)`)
- Filtros: type (enum), available (true/false/all)
- Busca: `->where(fn($q) => $q->where('name', 'like', "%{$search}%")->orWhere('producer', 'like', "%{$search}%"))`
- Scope `available()` já definido no Model
