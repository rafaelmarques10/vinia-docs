# Story 2.3: F003 — Importação de Vinhos via Planilha

**Status:** Done
**Epic:** 2 — Backoffice — Restaurante & Vinhos
**Sprint:** 2 (Semanas 3–4)
**Story Points:** 8
**Spec:** `vinia-specs/features/F003-wine-import.md`

---

## Story

Como **gerente autenticado**, quero importar múltiplos rótulos de uma planilha `.xlsx` ou `.csv`, para acelerar o cadastro inicial da carta de vinhos do restaurante.

---

## Contexto

Feature crítica para o onboarding — restaurantes com 200+ rótulos não vão cadastrar um a um. O processamento é assíncrono (Laravel Job) para não travar a UI. O sistema reporta erros linha a linha, importa o que for válido e ignora o que for inválido. Idempotente: rótulo existente (mesmo nome+produtor+safra) é atualizado, não duplicado.

**Referências de spec:**
- `vinia-specs/features/F003-wine-import.md`
- Template da planilha: colunas A–M conforme spec

### Colunas do template (F003 spec)
```
A: name (obrigatório)
B: producer (obrigatório)
C: vintage (opcional)
D: country (obrigatório)
E: region (opcional)
F: type (obrigatório: tinto|branco|rosé|espumante|sobremesa|fortificado)
G: grapes (opcional: "Cabernet Sauvignon, Merlot")
H: alcohol (opcional)
I: price (obrigatório: > 0)
J: description (opcional)
K: tasting_notes (opcional)
L: pairings (opcional)
M: available (opcional: true|false, default true)
```

### Idempotência
```php
// Chave de idempotência: (restaurant_id, name, producer, vintage)
$existing = Wine::where([
    'restaurant_id' => $restaurant->id,
    'name'          => $row['name'],
    'producer'      => $row['producer'],
    'vintage'       => $row['vintage'] ?? null,
])->first();

if ($existing) {
    $this->wineService->update($existing, $row);
    $result->updated++;
} else {
    $this->wineService->create($restaurant, $row);
    $result->imported++;
}
```
