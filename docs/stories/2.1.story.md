# Story 2.1: F001 — Gestão do Restaurante

**Status:** Done
**Epic:** 2 — Backoffice — Restaurante & Vinhos
**Sprint:** 1 (Semana 2)
**Story Points:** 5
**Spec:** `vinia-specs/features/F001-restaurant-management.md`

---

## Story

Como **gerente autenticado**, quero configurar os dados do meu restaurante (nome, logo e cores da marca) no backoffice, para que a carta digital exiba a identidade visual correta do estabelecimento.

---

## Contexto

O gerente acessa `/backoffice/settings/restaurant` e visualiza/edita as configurações do restaurante ao qual está vinculado. O slug é gerado automaticamente mas pode ser editado. O logo é enviado ao Cloudflare R2. As cores são hex e impactam diretamente na carta digital do tablet.

Multi-tenancy: um gerente só pode ver e editar o seu próprio restaurante. Admin Vinia pode editar qualquer restaurante.

**Referências de spec:**
- `vinia-specs/features/F001-restaurant-management.md`
- `vinia-specs/CONVENTIONS.md` — regras de upload e slugs

## Critérios de Aceite

- [x] **CA01**: Gerente acessa `/backoffice/settings` e vê formulário preenchido com dados atuais do restaurante
- [x] **CA02**: Ao alterar o nome e salvar, os dados são atualizados e o slug é recalculado automaticamente
- [x] **CA03**: Upload de PNG/JPG ≤ 2MB salva a logo no R2 em `restaurants/{id}/logo.{ext}` e atualiza `logo_url`
- [x] **CA04**: Upload de arquivo PDF retorna erro de validação (regra `mimes:png,jpg,jpeg`)
- [x] **CA05**: `primary_color` e `secondary_color` aceitam apenas hex válido (`#RRGGBB`)
- [x] **CA06**: `generateSlug("Café São João")` retorna `"cafe-sao-joao"`
- [x] **CA07**: Gerente só acessa configurações do próprio restaurante (RestaurantPolicy)
- [x] **CA08**: Upload com arquivo inválido não altera a logo atual

## Scope

**IN:**
- Livewire component `RestaurantSettings` (formulário reativo)
- `RestaurantService` com `update()`, `uploadLogo()`, `generateSlug()`
- `RestaurantPolicy` — gerente só edita o próprio restaurante
- Upload ao Cloudflare R2
- Validação de hex color e CNPJ format
- Preview visual da cor no formulário

**OUT:**
- Criação de restaurantes (feita pelo Admin Vinia fora do MVP)
- Desativação do restaurante (`active: false`) — disponível mas sem UI dedicada ainda
- Dashboard com métricas

### RestaurantPolicy
```php
// app/Policies/RestaurantPolicy.php
public function update(User $user, Restaurant $restaurant): bool
{
    if ($user->role === 'admin') return true;
    return $user->restaurant_id === $restaurant->id;
}
```
