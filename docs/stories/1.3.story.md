# Story 1.3: Models Eloquent + Relações Base

**Status:** Done
**Epic:** 1 — Foundation & Infraestrutura
**Sprint:** 1 (Semana 2)
**Story Points:** 3

---

## Story

Como **developer**, quero todos os Models Eloquent criados com suas relações, casts e factories, para que as features de negócio possam ser implementadas e testadas com dados realistas.

---

## Contexto

Com o banco criado (Story 1.2), é hora de criar os Models Eloquent correspondentes. Atenção especial ao `ComensalSession` (nome diferente da tabela) e ao UUID como PK. Factories são essenciais para os testes das próximas stories.

- Seeders de dados de demonstração
- Observer/Event hooks (não necessários no MVP)

## Dev Notes

### Models e suas particularidades

**Restaurant** (`app/Models/Restaurant.php`)
```php
protected $fillable = ['name', 'slug', 'cnpj', 'logo_url', 'primary_color', 'secondary_color', 'active', 'plan'];
protected $casts = ['active' => 'boolean'];
// Relações: users(), wines(), tablets(), comensalSessions()
```

**User** (`app/Models/User.php`)
```php
protected $fillable = ['name', 'email', 'password', 'role', 'restaurant_id'];
protected $hidden = ['password', 'remember_token'];
// Relação: restaurant() BelongsTo
```

**Wine** (`app/Models/Wine.php`)
```php
protected $casts = ['available' => 'boolean', 'price' => 'decimal:2', 'alcohol' => 'decimal:1'];
use SoftDeletes;
// Scope: scopeAvailable($query) → where('available', true)
// Relações: grapes() BelongsToMany via grape_wine, restaurant() BelongsTo
```

**Grape** (`app/Models/Grape.php`)
```php
protected $fillable = ['name'];
// Relação: wines() BelongsToMany via grape_wine
```

**Tablet** (`app/Models/Tablet.php`)
```php
protected $hidden = ['token'];
protected $casts = ['active' => 'boolean', 'last_seen_at' => 'datetime'];

public function isOnline(): bool
{
    return $this->last_seen_at?->gt(now()->subMinutes(5)) ?? false;
}
```

**ComensalSession** (`app/Models/ComensalSession.php`)
```php
protected $table = 'sessions';
protected $keyType = 'string';   // UUID
public $incrementing = false;

protected $casts = [
    'palate_profile' => 'array',
    'started_at'     => 'datetime',
    'ended_at'       => 'datetime',
];
// Relações: tablet() BelongsTo, restaurant() BelongsTo, aiInteractions() HasMany
```

**AiInteraction** (`app/Models/AiInteraction.php`)
```php
protected $fillable = ['session_id', 'type', 'input', 'prompt_sent', 'response', 'tokens_used', 'status'];
// Relação: session() BelongsTo (ComensalSession)
```

### BelongsToMany com tabela grape_wine
```php
// Wine.php
public function grapes(): BelongsToMany
{
    return $this->belongsToMany(Grape::class, 'grape_wine')
                ->withPivot('percentage');
}
```
