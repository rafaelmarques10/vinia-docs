## Story

Como **tablet autenticado**, quero acessar os endpoints REST da carta digital (dados do restaurante, listagem de vinhos com filtros e detalhe de rótulo), para que o React possa renderizar a carta completa com dados atualizados.

---

## Contexto

Esta story cria os endpoints que o frontend React consome. Todos protegidos pelo middleware `tablet.auth` (Story 3.1). As respostas devem ser padronizadas conforme `CONVENTIONS.md`. Os vinhos são filtrados e ordenados por tipo → país → nome por padrão (com possibilidade de filtros).

- `vinia-specs/CONVENTIONS.md` — estrutura de resposta padrão
- `vinia-specs/features/F005-digital-menu.md` — dados que o React precisa

### WineController (API)
```php
// app/Http/Controllers/Api/WineController.php
public function index(Request $request): WineCollection
{
    $tablet = $request->tablet;  // injetado pelo middleware
    $query = Wine::available()
                 ->where('restaurant_id', $tablet->restaurant_id)
                 ->with('grapes')
                 ->orderBy('type')->orderBy('country')->orderBy('name');

    // Filtros opcionais:
    if ($request->type)      $query->where('type', $request->type);
    if ($request->country)   $query->where('country', $request->country);
    if ($request->grape)     $query->whereHas('grapes', fn($q) => $q->where('name', $request->grape));
    if ($request->min_price) $query->where('price', '>=', $request->min_price);
    if ($request->max_price) $query->where('price', '<=', $request->max_price);

    return new WineCollection($query->get());
}

public function show(Request $request, Wine $wine): WineResource
{
    // Verificar que wine pertence ao restaurante do tablet
    abort_if($wine->restaurant_id !== $request->tablet->restaurant_id, 404);
    return new WineResource($wine->load('grapes'));
}
```
