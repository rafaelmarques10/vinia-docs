# Story 4.2: F006 — IA Recomendação (Prato + Perfil de Paladar)

**Status:** Done
**Epic:** 4 — Sofia IA — Recomendações
**Sprint:** 3 (Semana 6–7)
**Story Points:** 8
**Spec:** `vinia-specs/features/F006-ai-recommendation.md`, `vinia-specs/ai/PROMPTS.md`

---

## Story

Como **comensal**, quero perguntar à Sofia qual vinho harmoniza com meu prato ou receber uma sugestão baseada no meu perfil de paladar, para fazer uma escolha informada e satisfatória.

---

## Contexto

Esta story implementa os dois tipos de recomendação da Sofia sobre a infraestrutura da Story 4.1. O tipo 1 (por prato) recebe texto livre do comensal. O tipo 2 (por paladar) recebe o perfil coletado via 4 perguntas no React. Sofia deve sempre recomendar apenas vinhos da carta, nunca inventar rótulos, e jamais mencionar Anthropic/Claude.

**Referências de spec:**
- `vinia-specs/features/F006-ai-recommendation.md`
- `vinia-specs/ai/PROMPTS.md` — prompts exatos a implementar

## Dev Notes

### Prompt — Recomendação por Prato (de PROMPTS.md)
```
Tipo: recommend_dish

User prompt:
O comensal informou que irá pedir: "{dish}"

Por favor, recomende 2 a 3 vinhos da carta que harmonizem bem com este prato.

Para cada sugestão:
1. Cite o nome completo do vinho e a safra
2. Explique em 2-3 frases por que harmoniza com o prato
3. Mencione o preço

Formate a resposta de forma clara, com cada vinho bem separado.
Finalize com uma frase de incentivo para o comensal aproveitar a escolha.
```

### Prompt — Recomendação por Perfil (de PROMPTS.md)
```
Tipo: recommend_palate

User prompt:
Perfil de paladar do comensal:
- Preferência de cor: {color_preference}
- Corpo preferido: {body_preference}
- Perfil de sabor: {taste_preference}
- Faixa de preço desejada: R$ {price_range}

Com base neste perfil, recomende o(s) vinho(s) mais adequado(s) da carta.

Para cada sugestão:
1. Cite o nome completo e safra
2. Explique por que combina com o perfil descrito (2-3 frases)
3. Mencione o preço

Se nenhum vinho da carta atender exatamente ao perfil, seja honesta e sugira a melhor opção disponível.
```

### AiInteractionController — validação por tipo
```php
// store() — validação do input conforme type
$rules = match($request->type) {
    'recommend_dish' => ['input.dish' => 'required|string|max:500'],
    'recommend_palate' => [
        'input.color_preference' => 'required|in:tinto,branco,rosé,espumante,surpresa',
        'input.body_preference'  => 'required|in:leve,medio,encorpado',
        'input.taste_preference' => 'required|in:seco,frutado,doce',
        'input.price_range'      => 'required|string',
    ],
    default => throw new InvalidArgumentException('Tipo inválido'),
};

// Monta o user_prompt ANTES de salvar na AiInteraction
$userPrompt = match($request->type) {
    'recommend_dish'   => $service->buildDishPrompt($request->input['dish']),
    'recommend_palate' => $service->buildPalatePrompt($request->input),
};

// Salva o prompt montado em AiInteraction.input (para auditoria)
// E passa para o Job via AiInteraction.prompt_sent = system + user
```
