## Story

Como **developer**, quero ter o `AnthropicService`, o `ProcessAiRecommendationJob` e o endpoint de polling implementados, para que as features de recomendação da Sofia (Stories 4.2 e 4.3) possam ser construídas sobre esta infraestrutura.

---

## Contexto

A IA é o coração do produto. O fluxo é sempre: React faz `POST` → Laravel cria `AiInteraction` (status: pending) → dispara Job → Job chama Anthropic API → persiste resposta → React faz polling até `done` ou `failed`. Esta story implementa a infraestrutura genérica; os prompts específicos vêm nas próximas stories.

**Referências de spec:**
- `vinia-specs/features/F006-ai-recommendation.md` — arquitetura do fluxo

```php
// app/Services/AnthropicService.php

public function complete(string $systemPrompt, string $userPrompt): AnthropicResponse
{
    $response = Http::withHeaders([
        'x-api-key'         => config('services.anthropic.key'),
        'anthropic-version' => '2023-06-01',
        'content-type'      => 'application/json',
    ])
    ->timeout(config('services.anthropic.timeout'))
    ->post(config('services.anthropic.base_url') . '/messages', [
        'model'      => config('services.anthropic.model'),
        'max_tokens' => config('services.anthropic.max_tokens'),
        'system'     => $systemPrompt,
        'messages'   => [['role' => 'user', 'content' => $userPrompt]],
    ]);

    if ($response->failed()) {
        throw new AnthropicException($response->status(), $response->body());
    }

    return new AnthropicResponse(
        content: $response->json('content.0.text'),
        tokensUsed: $response->json('usage.input_tokens') + $response->json('usage.output_tokens'),
    );
}
```

### ProcessAiRecommendationJob
```php
// app/Jobs/ProcessAiRecommendationJob.php
class ProcessAiRecommendationJob implements ShouldQueue
{
    public $timeout = 60; // deixa margem além dos 30s do HTTP

    public function __construct(private AiInteraction $interaction) {}

    public function handle(AnthropicService $service): void
    {
        $this->interaction->update(['status' => 'processing']);
        $session = $this->interaction->session;
        $restaurant = $session->restaurant;
        $wines = Wine::available()->where('restaurant_id', $restaurant->id)->with('grapes')->get();

        $systemPrompt = $service->buildSystemPrompt($restaurant);
        // $userPrompt vem do $this->interaction->input — cada tipo monta o seu
        $userPrompt = $this->interaction->input; // prompt já montado pelo controller

        try {
            $result = $service->complete($systemPrompt, $userPrompt);
            $this->interaction->update([
                'status'      => 'done',
                'response'    => $result->content,
                'tokens_used' => $result->tokensUsed,
            ]);
        } catch (\Throwable $e) {
            $this->interaction->update(['status' => 'failed']);
            Log::error('AI Job failed', ['interaction' => $this->interaction->id, 'error' => $e->getMessage()]);
        }
    }
}
```

### Rate Limiting
```php
// Contar interações da sessão
$count = AiInteraction::where('session_id', $sessionId)
                      ->whereIn('status', ['done', 'processing', 'pending'])
                      ->count();
if ($count >= config('services.ai_rate_limit', 10)) {
    return response()->json([
        'error' => ['code' => 'RATE_LIMITED', 'message' => 'Você atingiu o limite de consultas desta sessão...']
    ], 429);
}
```

### Endpoints
```
POST /api/v1/ai/recommend
  Body: { session_id, type, input (user prompt já montado) }
  → Cria AiInteraction (pending), dispara Job, retorna { interaction_id }

GET /api/v1/ai/interactions/{id}
  → Retorna { status: 'pending|processing|done|failed', response: '...' }
```
