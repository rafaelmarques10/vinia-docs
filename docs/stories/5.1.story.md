## Story

Como **developer**, quero ter o projeto React configurado como PWA com roteamento, cliente HTTP autenticado, ThemeProvider dinâmico e modo quiosque funcionando no tablet, para que as telas da carta digital possam ser construídas sobre esta base.

---

## Contexto

O frontend React é uma aplicação separada (próprio repositório ou subpasta `frontend/`) que roda como PWA em tablets 10–12" em landscape. Comunica com a API Laravel via token do tablet (passado como query param ou env). O ThemeProvider aplica as cores do restaurante como CSS custom properties globais. Esta story é o equivalente da Story 1.1 para o frontend.

### ThemeProvider
```typescript
// src/components/ThemeProvider.tsx
export function ThemeProvider({ children }: PropsWithChildren) {
  const { data: restaurant } = useRestaurant();

  useEffect(() => {
    if (!restaurant) return;
    const root = document.documentElement;
    root.style.setProperty('--color-primary', restaurant.primary_color);
    root.style.setProperty('--color-secondary', restaurant.secondary_color);
  }, [restaurant]);

  return <>{children}</>;
}
```

### api.ts — cliente HTTP
```typescript
// src/services/api.ts
const token = import.meta.env.VITE_TABLET_TOKEN
  ?? new URLSearchParams(window.location.search).get('token')
  ?? '';

const client = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
  headers: { Authorization: `Bearer ${token}` },
});

export const api = {
  getRestaurant: () => client.get<RestaurantResponse>('/api/v1/restaurant').then(r => r.data.data),
  getWines: (params?: WineFilters) => client.get<WineListResponse>('/api/v1/wines', { params }).then(r => r.data.data),
  getWine: (id: number) => client.get<WineResponse>(`/api/v1/wines/${id}`).then(r => r.data.data),
  // Sessions e IA — próximas stories
};
```
